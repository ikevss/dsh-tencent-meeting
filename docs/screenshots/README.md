## 通用要求

| 项 | 要求 |
| --- | --- |
| 格式 | PNG，24 位色，不要 JPEG |
| 宽度 | 1600 px 起，2 倍屏直接截 3200 px 也可以 |
| 主题 | 统一用浅色主题，六张不要混用明暗 |
| 语言 | 界面用简体中文截一套；英文界面另截一套放 `en/` 子目录，文件名相同 |
| 裁切 | 只保留 DSH 窗口，不留桌面背景、任务栏、其它窗口 |
| 遮挡 | 涂掉真实姓名、真实会议号、真实入会链接、真实企业名；涂改使用纯色块，不要用模糊 |
| 光标 | 截图时把鼠标移出内容区，不要出现悬浮光标和 tooltip |
| 命名 | 严格用小写文件名 `home.png` / `detail.png` / `create.png` / `settings.png` / `auth.png` / `install.png` |

## 六张图各自的验收点

1. `home.png` 会议主页 —— 必须拍到：左栏「新建会议」、进行中/即将开始分组、右栏历史会议列表、相对时间（如「昨天 11:30 – 12:00」）、有转写徽标、「只看有转写」筛选、「加载更早的 30 天」、上次同步时间、底部「已连接 周朋」与「切换」。
2. `detail.png` 会议详情页 —— 必须拍到：返回箭头、会议主题、状态徽标、时间/会议号/入会链接、被企业策略覆盖的录制设置提示、参会人区块、页签（概览/逐字稿/智能纪要/时间轴/待办/会后产出）、右侧手风琴目录。
3. `create.png` 新建会议弹窗 —— 必须拍到：五种会议类型卡片、三步进度指示、字段全展开时的表单（主题/日期/开始/时长/密码/周期/入会限制/云录制/自动转写/等候室/参会人/备注）、两阶段确认里的预览页。
4. `settings.png` 设置页 —— 必须拍到：模型两级下拉（provider → model）、agent 预设下拉、四份产出技能开关、CLI 路径、缓存清理；保存失败要显示原因。
5. `auth.png` 未登录引导 —— 必须拍到：大图标、「去授权」主按钮、点击后的「等待授权中」与已等待秒数、「重新生成链接」；没有堆栈、没有英文报错。
6. `install.png` 插件市场安装页 —— 必须拍到：插件名 `dsh-tencent-meeting`、作者 ikevss、版本号 1.0.0、简介、MIT 标识、安装按钮。

## 替身 CLI 说明

`../../scripts/fake-tmeet.mjs` 只用于拍 `auth.png`：它按腾讯会议 CLI 的输出形状回一句话，不联网、不读 `~/.tmeet`、不发任何请求，只在隔离 profile 里通过 `tmeetBinary` 配进去。真实安装永远指向官方 `@tencentcloud/tmeet`。
